# Changelog

All notable changes to Starfruit Notes are documented here.

## [0.1.0] - 2026-11-08

### Added

- Native Windows desktop sticky-note interface.
- Add, edit, complete, delete, reorder, and locally persist tasks.
- Automatic daily rollover with unfinished-task carry-over prompt.
- Paper, plain, and dark themes.
- Desktop and always-on-top modes.
- System tray controls, global shortcut, and optional startup launch.
- Thirty-day local history.
- Custom Starfruit Notes application and shortcut icon.
